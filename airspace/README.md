# Airspace data

AeroflyATC accepts OpenAir v1/v2 airspace files. Put .txt, .openair, or .air files in the app's private airspace directory, then press LOAD LOCAL OPENAIR AIRSPACE.

The parser understands common AC, AN, AY, AF, AL, AH and DP records and reports airspaces containing the aircraft position.

Do not treat imported airspace as an official navigation source. Check the source's validity date and use current official aeronautical information for real flying.

OpenAir is a widely used plain-text airspace interchange format; the extended format adds airspace type, frequency, station, activation and transponder metadata.
